# Font sources

DM Sans and DM Serif Display are distributed under their respective SIL Open Font Licenses included in this directory. These WOFF2 files were converted from the upstream Google Fonts TTF files without changing outlines, names or character coverage.

- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/dmserifdisplay

The site serves these files locally; it no longer requests styles or fonts from Google Fonts. Keep the licence files when redistributing.
